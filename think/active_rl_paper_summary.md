## 1. 研究背景与动机

### 1.1 问题场景

在实际应用中，智能体与环境进行在线交互的成本可能非常高昂：

- **医学试验**：选择合适的患者进行治疗，需要在有限的预算内收集最有价值的数据
- **自动驾驶导航**：在复杂环境中训练智能体，某些区域可能不适合探索
- **受限的资源预算**：只能进行有限次数的agent-environment交互

### 1.2 研究问题

> **核心问题**：在已有离线数据集的情况下，如何用最少的在线交互来提升智能体的策略性能？

这类似于监督学习中的**主动学习(Active Learning)**问题，但在RL中更加复杂：

| 监督学习 | 强化学习 |
|---------|---------|
| 选择未标记的数据点进行标注 | 决定**在哪里、如何、到什么程度**探索环境 |
| 数据点是静态的 | 轨迹是探索策略的随机函数 |

### 1.3 现有方法局限

- **离线强化学习**：只能从固定数据集中学习，无法收集新数据
- **在线强化学习**：需要大量环境交互，成本高昂
- **探索方法**：通常假设可以从任意状态重置，不适合受限场景

## 2. 问题形式化

### 2.1 MDP定义

标准MDP：$M = (S, A, T, r, \rho, \gamma)$

- $S$：状态空间
- $A$：动作空间
- $T$：转移函数
- $r$：奖励函数
- $\rho$：初始状态分布
- $\gamma$：折扣因子

### 2.2 离线数据集

$D = \{(s_i, a_i, s'_i, r_i, d_i)\}_{1 \leq i \leq N}$

### 2.3 主动学习智能体

主动学习智能体 $\mu = (I, \pi, \beta)$ 包含三个组件：

1. **初始状态选择函数** $I: S \rightarrow \mathbb{R}$：决定从给定状态开始收集轨迹的效用
2. **探索策略** $\pi: S \rightarrow \Delta A$：将状态映射到动作概率分布
3. **终止函数** $\beta: S \rightarrow \{0, 1\}$：决定是否终止当前轨迹

### 2.4 目标函数

$$\mu^* = \arg\max_{\mu=(I,\pi,\beta)} \mathbb{E}_{\tau \sim T_\mu}[V^{\pi_{Alg}(D \cup \{\tau\})}]$$

即：通过收集新样本，最大化在增强数据集上训练策略的性能。

## 3. 算法设计

### 3.1 核心思想

**基于表示的认知不确定性(Epistemic Uncertainty)方法**

- 训练表示模型集成 $\{E_k\}_{k=1}^K$ 来编码状态和状态-动作对
- 通过模型之间的**分歧(disagreement)**来估计不确定性
- 高不确定性区域 = 数据覆盖不足的区域 = 需要优先探索的区域

### 3.2 表示模型训练

使用**增强的噪声对比损失**训练表示模型：

$$L = \log(\sigma(v \cdot v^+)) + \log(1 - \sigma(v \cdot v^-)) - \lambda ||\hat{v}^+ - v^+||^2$$

其中：
- $v, v^+$：相似状态（锚点和正样本）的嵌入
- $v^-$：负样本的嵌入
- $\hat{v}^+ = E(s, a)$：状态-动作对的嵌入
- $\lambda$：超参数

**两个建模目标**：
1. 相似状态应该在潜在空间中聚类
2. 状态-动作对的嵌入应该与对应的下一状态嵌入对齐

### 3.3 不确定性估计

对于给定的状态或状态-动作对，计算K个模型嵌入之间的分歧：

$$S_{i,j} = ||v_i - v_j||^2 \quad \text{for } i,j = 1, 2, ..., K$$

使用S中最大元素的值作为模型对该环境区域的认知不确定性的代理。

### 3.4 初始状态选择

$$Uncertainty(s_i) = \max_{k,k'} ||E^k_s(s_i) - E^{k'}_s(s_i)||^2$$

选择使表示模型集成不确定性最大的候选初始状态。

### 3.5 探索策略

1. 从当前策略 $\pi$ 采样M个候选动作
2. 计算每个动作对应的状态-动作对不确定性
3. 选择使不确定性最大的动作执行
4. 使用 $\epsilon$-greedy变体控制探索程度

## 4. 算法流程

```
Algorithm: Active Offline Reinforcement Learning

输入: D (离线数据集), Alg (离线RL算法), B (交互预算)

初始化: T ← ∅

while B > 0 do
    学习 μ = (I, π, β) 基于 D ∪ T
    从 ˆρ 采样候选初始状态 C
    sinit ← argmax_{1≤i≤|C|} I(si)  // 选择最不确定的初始状态
    
    // 从 sinit 开始收集轨迹
    s ← sinit, τ ← ∅
    while B > 0 and β(s) = 0 do
        a ∼ π(s)  // 从探索策略采样动作
        s' ∼ T(s, a)
        r = r(s, a)
        τ ← τ ∪ {(s, a, s', r)}
        B ← B - 1
        s ← s'
    T ← T ∪ τ
    
    π_Alg ← Alg(D ∪ T)

返回: 改进后的策略 π_Alg
```

## 5. 实验设置

### 5.1 环境

| 环境 | 描述 |
|------|------|
| **Maze2d** | 2D平面上控制小球导航到目标 |
| **AntMaze** | 控制虚拟蚂蚁机器人在迷宫中导航 |
| **HalfCheetah/Hopper/Walker2d** | MuJoCo locomotion任务 |
| **CARLA** | 自动驾驶车辆模拟器 |
| **IsaacSim-Go1** | NVIDIA Isaac模拟器控制Unitree Go1四足机器人 |

### 5.2 数据集处理

- **Maze2d**：剪枝接近目标状态附近的轨迹
- **AntMaze**：随机采样30%的轨迹
- **Locomotion**：随机采样30%的轨迹
- **CARLA**：使用预定义专家策略收集数据

### 5.3 基线方法

- **BC**：行为克隆
- **Offline**：纯离线训练（TD3+BC, IQL, CQL）
- **Offline + FT**：离线 + 标准微调
- **Offline + RND**：离线 + 随机网络蒸馏

## 6. 实验结果

### 6.1 主要结果

| 指标 | 结果 |
|------|------|
| 在线交互减少 | **最多75%** |
| 性能提升 | 在各种环境下持续优于基线 |
| 兼容性 | 可与TD3+BC, IQL, CQL等离线算法结合 |

### 6.2 消融实验结论

| 组件 | 结论 |
|------|------|
| **主动初始状态选择** | 无论使用何种探索策略，主动选择都优于随机选择 |
| **不确定性探索策略** | 优于随机探索和使用离线策略 |
| **最大分歧指标** | 比方差、均值等指标更适合估计不确定性 |

### 6.3 零初始数据集实验

即使在没有任何初始离线数据的情况下，本文方法仍优于在线TD3算法。

## 7. 关键创新点

1. **首个针对顺序决策问题的主动学习方法**：将主动学习思想从监督学习扩展到RL领域

2. **表示感知的不确定性估计**：利用表示模型集成而非Q值网络来估计不确定性

3. **高效的数据收集策略**：通过聚焦于高不确定性区域，显著减少所需的在线交互

4. **灵活的框架**：可与多种离线RL算法结合使用

5. **实际应用价值**：适用于医学试验、自动驾驶、机器人控制等实际场景

## 8. 与EasyCarla的关系

这篇论文的方法可以直接应用于EasyCarla项目中的CARLA环境：

1. **离线数据收集阶段**：使用现有的专家策略或人类示范数据构建离线数据集

2. **主动探索阶段**：
   - 训练表示模型集成来编码状态（车辆位置、速度、周围环境等）
   - 识别离线数据覆盖不足的区域（如某些路口、天气条件）
   - 从高不确定性区域开始主动收集新轨迹

3. **持续学习**：用收集到的新数据更新策略，迭代优化

### 潜在应用场景

- 训练自动驾驶车辆适应**罕见交通场景**（紧急刹车、异常车辆行为）
- 适应**不同天气条件**（雨天、雾天、夜间）
- 学习**复杂路口**的导航策略

## 10. 总结

本文提出了**ActiveRL**，一种在有限在线交互预算下增强离线强化学习的主动探索方法。通过训练表示模型集成并利用认知不确定性来指导数据收集，该方法在多种连续控制环境中实现了显著的性能提升和数据效率优化。

这项工作是**首个将主动学习思想应用于顺序决策问题**的研究，为资源受限场景下的强化学习提供了新的解决思路。
