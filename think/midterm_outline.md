# 中期答辩汇报大纲

## 一、研究背景与研究现状

- **1.1 自动驾驶技术发展背景**
  - 从传统模块化方案到端到端自动驾驶的技术演进
  - 端到端自动驾驶的核心思想与发展现状
  - 端到端方案面临的主要挑战（泛化性、安全性、决策可解释性等）

- **1.2 强化学习在自动驾驶中的研究意义**
  - 强化学习如何实现策略的自我优化
  - 离线强化学习避免在线交互风险的优势
  - 在线强化学习持续提升策略性能的必要条件
  - 表征学习与强化学习结合的趋势

- **1.3 当前主流方法研究现状**
  - 离线强化学习方法（BC、IQL、CQL、Diffusion RL等）
  - 表征学习在RL中的应用（contrastive learning、encoder-decoder等）
  - 在线微调与主动学习策略
  - CARLA仿真平台下的主流方法对比

- **1.4 现有方法的主要局限**
  - 离线RL中分布偏移与价值过估计问题
  - 表征空间不稳定导致RL训练困难
  - 在线微调数据效率低、样本质量参差不齐
  - 现有方法缺乏对复杂场景与简单场景的差异化处理能力

- **1.5 本课题的研究切入点**
  - 以表征学习为离线RL提供稳定初始化
  - 以主动在线微调提升数据效率与策略质量
  - 以快慢双系统架构覆盖简单与复杂场景
  - 以自进化机制实现长期性能持续提升


## 二、课题目标与整体方案

- **2.1 课题总体研究目标**
  - 构建一套端到端自动驾驶强化学习框架
  - 覆盖离线训练与在线微调的完整闭环
  - 实现简单场景高效处理与复杂场景智能应对的统一架构
  - 支撑长期部署下的模型自进化能力

- **2.2 三阶段技术路线设计**
  - 第一阶段：离线表征学习与离线强化学习（已完成）
  - 第二阶段：VLA慢思考模型构建（待开展）
  - 第三阶段：快慢协同与自进化系统（待开展）

- **2.3 强化学习主线任务定义**
  - 在CARLA仿真环境中定义连续控制任务
  - 状态空间：307维结构化感知信息（自车状态、道路信息、LiDAR、近邻车辆、导航路点）
  - 动作空间：3维连续动作（油门、转向、刹车）
  - 奖励函数：速度奖励、车道保持奖励、动作平滑奖励、停车惩罚、碰撞惩罚、偏离道路惩罚

- **2.4 快慢双系统总体架构思路**
  - 简单场景由快速RL策略直接处理
  - 复杂场景切换至慢思考VLA模型进行推理
  - 切换器基于场景复杂度与决策置信度触发
  - 两个系统共享底层表征，降低计算开销

- **2.5 各章节之间的逻辑关系**
  - 第一章离线+在线RL是整个系统的性能基座
  - 第二章VLA扩展了系统处理复杂决策的能力边界
  - 第三章快慢协同与自进化赋予系统长期适应与自我改进能力


## 三、阶段成果与实现情况

- **3.1 任务场景与环境建模**
  - CARLA仿真环境配置与Town03测试场景
  - 感知输入结构：ego_state(9维) + lane_info(2维) + lidar(240维) + nearby_vehicles(20维) + waypoints(36维)
  - 总计307维状态空间，统一拼接为浮点向量
  - 3维连续动作空间：throttle ∈ [0,1]、steer ∈ [-1,1]、brake ∈ [0,1]
  - 终止条件：碰撞、离线道路、车道偏离过大、逆行、时间超时

- **3.2 状态表征与奖励机制设计**
  - 离线对比表征学习（InfoNCE损失）
    - 正样本：同一轨迹内时间相邻的状态对
    - 负样本：跨轨迹或时间间隔较远的状态对
    - 编码器结构：307 → 256 → 256 → 64（latent_dim）
    - 温度参数 τ = 0.07，负样本数 N = 255
  - 奖励函数分解：
    - 速度奖励：`r_speed = v_t` if `v_t <= v_des`，else `r_speed = -(v_t - v_des)`
    - 车道保持：`r_lane = -δ_t`（横向偏移量）
    - 动作平滑：`r_smooth = -0.5|a_t^{lat}|`（横向动作绝对值）
    - 停车惩罚：`r_stop = -1.0` if `d_front > 10m and v_t < 0.1`
    - 碰撞惩罚：`r_col = -100.0`（发生碰撞时触发）
    - 偏离道路惩罚：`r_off = -100.0`（离开可行驶区域时触发）
  - 成本函数：碰撞/偏离道路计 cost = 20.0，超速计额外 cost

- **3.3 离线强化学习方法实现**
  - Behavior Cloning（BC）基线
    - 直接拟合专家数据的策略分布
    - 作为离线RL的性能下界参考
  - Diffusion Q-Learning（Diffusion QL）核心方法
    - 扩散模型作为策略先验，结合双Q网络进行Offline RL
    - Critic损失：TD目标 `y_t = r_t + (1-d_t)γ min(Q_ψ1, Q_ψ2)`
    - Actor损失：`L_actor = L_BC + η · L_Q`
    - L_BC：行为克隆负对数似然
    - L_Q：Q引导的扩散采样动作评分损失
    - 候选动作打分采样：生成50个候选动作，基于 critic 价值函数加权采样
    - 支持可选的 RL encoder 微调或冻结两种模式
  - 训练配置：
    - offline_ratio = 1.0（纯离线训练）
    - encoder 可选冻结（encoder_only）或微调（full）
    - 同时支持 priority 权重采样

- **3.4 在线强化学习扩展实现**
  - 在线数据采集与混合回放
    - 在线 buffer 收集交互数据
    - offline_ratio 自适应调度（warmup → linear ramp → adaptive adjustment）
    - 支持纯 baseline 模式（无创新模块）和 active 模式（完整创新模块）
  - 主动不确定性估计
    - 多头 Q 网络 ensemble（K = 5 个轻量 head）
    - 不确定性指标：`σ_u(z,a)`（多头分歧标准差）、`Δ_u(z,a)`（max-min 分歧）
    - 基于不确定性的动作选择：`Score(a|s) = μ_u(z,a) + λ_u · σ_u(z,a)`
  - 新颖度引导的样本保留
    - 基于参考编码器的状态新颖度评估：`Nov(s_t) = min ||z_t^{ref} - m||₂`
    - 综合保留分数：`R_t = λ_u · σ_u(z_t,a_t) + λ_n · Nov(s_t)`
    - 超过阈值 τ_r 的样本强制保留进在线 buffer
  - 完整训练流程：encoder 预热 → 多头 head 预热 → active 在线微调
  - 在线阶段指标记录：reward、cost、collision_rate、offroad_rate、retention_rate、uncertainty/novelty 统计

- **3.5 阶段性实验结果分析**
  - BC、Diffusion QL（baseline）、Diffusion QL（full）三条曲线的离线训练 loss 收敛对比
  - 离线阶段各方法在 CARLA 中的 rollout 评测指标：
    - avg_reward、avg_cost、avg_steps、collision_rate、offroad_rate
  - 多 seed（0/1/2）均值 ± 标准差实验，绘制带方差阴影的对比曲线
  - 在线微调后的策略性能提升分析
  - 消融实验：baseline online vs uncertainty only vs uncertainty + novelty

- **3.6 代码组织与实验入口**
  - 离线表征学习入口：`python example/representation/train_representation.py`
  - 离线RL训练入口：`python example/train_diffusion_ql.py`
  - 在线finetune入口：`python example/train_online_finetune.py --online_mode baseline/active`
  - CARLA评测入口：`python example/run_dql_in_carla.py`
  - 离线批量评测画图：`python example/evaluate_offline_actor_sweep.py --seeds 0 1 2 --episodes 5`


## 四、后续研究内容与思路

- **4.1 面向复杂场景的VLA建模（第二章）**
  - **数据来源与构建策略**
    - 专家演示数据中抽取高复杂度决策片段
    - 自动/半自动文本标注（场景描述、决策意图、风险等级）
    - 数据schema设计：`{image_i, behavior_i, state_i, traj_i, text_i}`，traj_i 为未来4秒轨迹
  - **VLA模型结构设计**
    - 输入层：当前视角图像 + 结构化状态 + 文本指令
    - 视觉编码器：预训练视觉backbone提取图像特征
    - 跨模态对齐：将视觉特征与状态表征映射至统一空间
    - 输出层：4秒轨迹预测（共12个时间步，每步3维动作）
  - **训练路线**
    - 第一步：监督预训练，在专家轨迹数据上做行为克隆
    - 第二步：高层次RL微调（稀疏奖励 + 课程学习）
    - 第三步：与第一章RL encoder共享表征，降低训练开销
  - **在快慢系统中的定位**
    - 作为慢思考网络，处理复杂交叉路口、拥堵路段、行人密集等场景
    - 输出4秒完整轨迹供执行层执行

- **4.2 快慢协同决策机制设计（第三章）**
  - **切换器构建**
    - 切换评分函数：`C_t = w₁U_t^{RL} + w₂N_t + w₃X_t^{scene} + w₄D_t^{conflict} - w₅P_t^{VLA}`
    - 各指标含义：U_t^{RL}=RL策略置信度，N_t=场景新颖度，X_t^{scene}=场景复杂度，D_t^{conflict}=决策冲突度，P_t^{VLA}=VLA可用性
  - **迟滞切换机制**
    - 进入VLA：`C_t > θ_on` 且持续 `T_on` 步
    - 切换回RL：`C_t < θ_off` 且持续 `T_off` 步
    - 避免频繁震荡，提升系统稳定性
  - **输出接口设计**
    - VLA输出：12步×3维的短期轨迹序列
    - RL输出：单步3维动作
    - 执行层统一转换为底层控制指令

- **4.3 基于反馈的自进化机制**
  - **失败归因**
    - 失败类型分类：`RL-error、VLA-error、Gate-error`
    - 自动判别方法：对比两系统输出差异与实际轨迹偏差
  - **数据闭环构建**
    - 部署运行 → 实时监测 → 失败检测 → 归因分析 → 数据回流 → 模型重训练
    - 优先收集归因于RL或VLA自身缺陷的失败样本
  - **持续优化策略**
    - 高价值失败样本优先加入训练集
    - 根据失败频率动态调整各模块训练权重
    - 避免对单一模块的过度修正而破坏已有能力

- **4.4 整体闭环系统验证方案**
  - 分阶段验证：先验证RL vs VLA切换的正确性，再验证自进化效果
  - 仿真验证：在CARLA中设计多样化的测试场景，覆盖简单到复杂梯度
  - 真实迁移评估：验证表征迁移与策略迁移的鲁棒性
  - 长期运行测试：模拟持续部署场景下的性能衰减与恢复

- **4.5 后续实验设计与验证路线**
  - 第一步：完成VLA数据集构建与模型训练
  - 第二步：实现快慢切换器并进行对比实验（仅RL vs 仅VLA vs 快慢协同）
  - 第三步：引入自进化机制，验证长期性能提升
  - 评测指标：任务完成率、平均决策质量、场景覆盖率、系统响应延迟

## 附录：第一章公式速览

### MDP定义
- 折扣MDP：`M = (S, A, P, r, γ)`
- 离线数据集：`D_off = {(s_t, a_t, r_t, s_{t+1}, d_t)}_{t=1}^{N}`
- 在线数据集：`D_on = {(s_t, a_t, r_t, s_{t+1}, d_t)}_{t=1}^{M}`

### 表征学习
- 状态编码：`z_t = E_φ(s_t)`
- InfoNCE对比损失：`L_rep = -log exp(sim(z_i, z_j^+)/τ) / (exp(sim(z_i, z_j^+)/τ) + Σ exp(sim(z_i, z_k^-)/τ))`

### 离线强化学习
- TD目标：`y_t = r_t + (1-d_t)γ min(Q_ψ1(s',a'), Q_ψ2(s',a'))`
- Critic损失：`L_critic = E[(Q_ψ1 - y_t)² + (Q_ψ2 - y_t)²]`
- Actor损失：`L_actor = L_BC + η · L_Q`

### 在线主动微调
- 多头Q分歧：`μ_u = 1/K Σ Q_u^{(k)}`，`σ_u = sqrt(1/K Σ (Q_u^{(k)} - μ_u)²)`
- 动作评分：`Score(a|s) = μ_u(z,a) + λ_u · σ_u(z,a)`
- 新颖度：`Nov(s_t) = min_{m∈M_ref∪M_on} ||z_t^{ref} - m||₂`
- 混合回放比例：`ρ_e = f(e, α_e, ΔJ_e)`
